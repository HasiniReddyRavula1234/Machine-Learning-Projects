A regression project for predicting housing prices using demographic and geographical features.

---

### 🔍 Industrial Defect Detection

A computer vision project for detecting defects in industrial products using **PatchCore** and **Anomalib**.

The project uses the **MVTec AD dataset** and focuses on anomaly detection in industrial images.

**Technologies:**

* PyTorch
* Anomalib
* PatchCore
* MVTec AD
* Computer Vision

Example anomaly scores:

```text
Normal Image  → 0.2450
Defective Image → 0.9606
```

Higher anomaly scores indicate a stronger likelihood of an abnormal/defective sample.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/HasiniReddyRavula1234/Machine-Learning-Projects.git
```

### 2. Navigate to the repository

```bash
cd Machine-Learning-Projects
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the notebooks

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Then open the notebook corresponding to the project you want to explore.
